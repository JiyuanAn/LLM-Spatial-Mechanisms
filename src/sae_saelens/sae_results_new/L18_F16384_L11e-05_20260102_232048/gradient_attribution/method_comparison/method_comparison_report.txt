✗ Ablation method shows WEAK causal evidence
  (spatial ablation causes 0.50x more damage than random)

6. ADVANTAGES & DISADVANTAGES
------------------------------------------------------------
Gradient Method:
  ✓ Much faster (no need to re-run model for each feature)
  ✓ Provides continuous importance scores
  ✓ Can analyze all features simultaneously
  ✗ Attribution is correlation, not causation
  ✗ Sensitive to gradient noise

Ablation Method:
  ✓ Provides causal evidence (intervention-based)
  ✓ Direct measurement of feature impact
  ✗ Very slow (requires re-running model many times)
  ✗ Binary effect (ablate or not)
  ✗ Doesn't scale to per-feature analysis

7. RECOMMENDATIONS
------------------------------------------------------------
Use Gradient Method when:
  - You need fast feature importance screening
  - You want to analyze many features
  - You need fine-grained attribution scores

Use Ablation Method when:
  - You need causal evidence
  - You want to validate specific features
  - You need interpretable intervention effects

Best Practice:
  1. Use Gradient method for initial screening
  2. Use Ablation method to validate top candidates
  3. Combine both for comprehensive analysis
